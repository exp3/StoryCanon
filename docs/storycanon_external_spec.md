# StoryCanon 外部仕様書

## 1. サービス概要

### 1.1 サービス名

仮称：**StoryCanon**

### 1.2 コンセプト

StoryCanon は、ChatGPT で生成・相談した物語を、作品ごとに非公開で保存し、キャラクター、世界観、伏線、章要約、修正TODO、現在のストーリー状態を整理するストーリー管理アプリである。

ユーザーは ChatGPT アプリ内で物語の生成・レビュー・相談を行い、必要な本文やメモを StoryCanon 側に保存する。

StoryCanon 自体は、MVP段階では AI 生成を行わず、ChatGPT で生成された内容の保存・整理・再利用を担う。

### 1.3 主要な価値

- ChatGPT で生成した本文を作品ごとに保存できる
- キャラクター、世界観、伏線、プロット、修正TODOを整理できる
- 長編化しても、現在のストーリー状態を維持しやすい
- 次回 ChatGPT で続きを生成するときに、保存済みの状態を参照できる
- 公開プラットフォームとは分離し、初期版ではすべて非公開で扱う

### 1.4 想定ユーザー

- ChatGPT で小説や物語を生成して読んでいる人
- 自分では書けないが、自分好みの物語を読みたい人
- 小説、TRPG、漫画原作、ゲームシナリオを作る人
- 長編作品のキャラクターや伏線管理に困っている人
- 複数作品やシリーズを管理したい創作者

```text

  ↓
ChatGPT アプリ
  ↓

  ↓
StoryCanon Web アプリ / DB
```

### 2.2 ChatGPT 側で行うこと

- 要約作成

### 2.3 StoryCanon 側で行うこと

- 作品保存
- 本文保存
- 章・シーン管理
- キャラクター保存
- 世界観メモ保存
- 伏線保存
- プロットスレッド保存
- 修正TODO保存
- ストーリー状態スナップショット保存
- 次回生成用コンテキスト提供
- Markdown / JSON エクスポート

## 3. アカウント仕様

### 3.1 アカウント作成

ユーザーは StoryCanon の Web アプリでアカウントを作成する。

MVPでは以下を想定する。

- Google OAuth ログイン
- メールアドレスログインは後回し

### 3.2 ChatGPT 連携

ユーザーは ChatGPT アプリ内で StoryCanon を連携する。

MVPでは正式な Apps SDK 公開前提ではなく、MCP 風 API を用意し、将来の ChatGPT Apps / MCP 連携に移行しやすい構成にする。

### 3.3 連携後にできること

- 作品一覧を取得する
- 新規作品を作成する
- 作品の現在状態を取得する
- 生成本文を保存する
- キャラクターメモを保存する
- 世界観メモを保存する
- 伏線を保存する
- プロットスレッドを保存する
- 修正TODOを保存する
- ストーリー状態を保存する
- 次回生成用コンテキストを取得する

## 12. データ削除仕様

ユーザーは以下を削除できる。

- 作品
- シーン
- キャラクター
- メモ
- 伏線
- 修正TODO
- アカウント

作品データの削除は、MVPでは論理削除とする。

削除済みデータは通常の一覧、作品詳細、ChatGPT連携用コンテキスト、エクスポートには含めない。

ChatGPT / MCP 連携からも、ユーザーの明示指示がある場合は作品データを論理削除できる。

ただし、ChatGPT / MCP 連携からアカウント削除はできない。アカウント削除は Web アプリ側のみで行う。

MCP 連携には、保存・更新・削除指令をロールバックするための操作を用意する。

ロールバックは、直前の指令だけでなく、可能な範囲で特定の指令IDまたは一連の指令単位を指定して実行できるようにする。

1つのユーザー指示で複数のデータが作成・更新された場合も、その指令単位でまとめてロールバックできる。

代表例：

```text
直前に保存したシーンを取り消して
今追加した伏線を削除して
さっきの削除を元に戻して
この保存指令全体をロールバックして
```

アカウント削除時は以下を削除対象とする。

- 作品データ
- メモ
- 本文
- 連携情報
- APIトークン

ただし、決済履歴など法令・会計上必要な情報は一定期間保持する可能性がある。

## 14. プラン超過時の挙動

### 14.1 作品数超過

- 新規作品作成不可
- 既存作品の閲覧は可能
- アップグレード導線を表示

### 14.2 本文量超過

- 既存本文の閲覧は可能
- 新規シーン保存不可
- 本文編集保存不可
- エクスポートは可能
- アップグレード導線を表示

### 14.3 キャラクター数超過

- 新規キャラ作成不可
- 既存キャラ編集は可能

### 14.4 Pro解約後

PlusまたはFreeの上限を超えている場合：

- 閲覧可能
- 新規追加不可
- エクスポート可能
- 削除可能
- 再課金で編集再開

## 16. 代表的なユーザーフロー

### 16.1 新規作品作成

1. ユーザーが StoryCanon に登録
2. ChatGPT で StoryCanon を連携
3. ChatGPT に「近未来SFを作りたい」と相談
4. ChatGPT が作品概要を作る
5. ユーザーが「この設定で作品を作成して」と指示
6. StoryCanon に非公開作品が作成される

### 16.2 本文生成と保存

1. ユーザーが ChatGPT に「第1話を書いて」と依頼
2. ChatGPT が本文を生成
3. ユーザーが「この本文を第1章第1シーンとして保存して」と指示
4. StoryCanon に本文が保存される
5. ChatGPT が要約・登場キャラ・伏線候補を整理
6. ユーザーが承認
7. StoryCanon にストーリー状態が保存される

### 16.3 続き生成

1. ユーザーが「前回の続きから書いて」と依頼
2. ChatGPT が StoryCanon から現在状態を取得
3. 現在状態をもとに次シーン候補を提示
4. ユーザーが候補を選ぶ
5. ChatGPT が本文生成
6. ユーザーが保存指示
7. StoryCanon に本文と状態を保存

### 16.4 レビュー

1. ユーザーが「第3章をレビューして」と依頼
2. ChatGPT が第3章と関連設定を取得
3. レビュー結果を提示
4. ユーザーが「指摘をTODOにして」と指示
5. StoryCanon に修正TODOが保存される

## 19. 外部仕様としての最終定義

StoryCanon は、ChatGPT で生成・相談した物語を保存し、キャラクター・世界観・伏線・章要約・現在のストーリー状態を非公開プロジェクトとして整理する Web アプリである。

ユーザーは ChatGPT アプリ内から StoryCanon を連携し、生成された本文やレビュー結果、キャラクターメモ、伏線、修正TODOを自分の StoryCanon アカウントに保存できる。

生成そのものは ChatGPT 上で行い、StoryCanon は作品データの保存・整理・再利用を担う。

公開プラットフォーム機能は初期版には含めず、将来的に別機能または別サービスとして提供する。
